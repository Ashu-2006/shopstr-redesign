08 — Hard rules

What keeps it
Shopstr

✕
No shadows. Separate with spacing first; a 1.5px ink stroke only when needed.
✓
Neutral primary. Primary buttons & backgrounds are ink/paper. Purple is the accent.
✓
Black text. White only over ink (#121212) and purple (#5A51E5).
✓
Mono for value. Every sat amount, rating & count in Space Mono, tabular.
✓
Shapes as assets. Circle/square/triangle/semicircle/arrow used liberally.
✕
Don't mix layouts. Reference one Pinterest layout per component and build it fully.
